# farahinani.com — legacy site archive

Archived snapshot of the **deployed** farahinani.com, kept for reference before the
WordPress revamp.

- **Captured:** 30/08/2026, downloaded from Hostinger `public_html`.
- **Asset build date:** 24/12/2025 (from file timestamps).
- **Type:** Next.js **static export** — built, minified output. This is **not** the
  original source code (no components, no `package.json`, no build config).
- **Contents:**
  - `index.html`, `404.html`, `_next/` — the exported Next.js portfolio
  - `mohito/`, `youtubemock/` — standalone demo sub-projects (Vite builds), also exported
- **Excluded:** `.DS_Store`, `Thumbs.db` (OS junk).

## Purpose
Point-in-time backup of what was live. The new portfolio is being built fresh on
WordPress in the `farahinani-portfolio` repo.
